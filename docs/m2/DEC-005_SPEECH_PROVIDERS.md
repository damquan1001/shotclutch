# DEC-005 — M2 speech providers

Selected and implemented on `codex/m2-smart-rough-cut`; updated 2026-11-08. This decision covers M2 ASR. Embeddings and visual model profiles remain M3 work.

New Smart Cut workspaces select `faster-whisper-tiny.en`: the same English CPU INT8 model family and inference settings used by the local OpenGling reference. Its model binary is 75,537,502 bytes; the four pinned artifacts total about 78 MB. The catalogue pins SYSTRAN revision `0d3d19a32d3338f10357c0889762bd8d64bbdeba`, sizes and SHA-256 hashes. `faster-whisper-base.en` is an optional larger English profile. Existing saved analyses retain their model; the legacy Candle `whisper-base` profile remains available, including multilingual use. The general Transcript panel's existing default is unchanged.

Fast profiles use an isolated Python runtime under the local data directory, installed only through the explicit model installation action. Python 3.10 or newer must be available, or selected through `SHOTCLUTCH_PYTHON`. Installation pins faster-whisper 1.2.1, CTranslate2 4.8.3, ONNX Runtime 1.23.2, PyAV 17.1.0, tokenizers 0.23.3, NumPy 2.2.6 and huggingface-hub 2.2.0. The worker verifies these versions. Recognition uses CPU INT8, at most eight CPU threads, beam size five, Silero VAD, word timestamps and no conditioning on previous text. Inference runs offline and accepts bounded PCM rather than paths or URLs. The parent owns and cancels the worker process; it retains the loaded model between chunks.

Weights and runtime are stored outside the project and are not bundled or committed. Installation displays phase, byte progress, cancellation and failure. Artifacts are verified before use. Runtime installation uses the Python package index and model acquisition uses the pinned catalogue host. Local inference sends no audio to a provider.

Analysis starts only on request. Fast recognition uses five-minute audio chunks with up to one second of context at each end; legacy Candle recognition and silence-only use 20 seconds. Selected stream/channel, absolute source word timing and durable completed coverage are preserved. Midpoints assign boundary words once. Volatile segment progress is separate from acknowledged completed coverage. Cancellation preserves completed chunks; resume revalidates the source, model artifacts and inference profile. Silence-only is explicit and creates no transcript words. Unknown cleanup confidence is shown as unknown.

The user's requested AssemblyAI option is an additional cloud provider in Setup. Selecting it and starting transcription uploads bounded mono PCM audio chunks (five minutes plus context), polls the service, maps returned word times to source time, and retains completed coverage. Credentials remain in process memory or the operator's `ASSEMBLYAI_API_KEY` environment variable; they are not project fields. Errors omit the key and provider response bodies. Local Whisper remains the default. Parser/timing/error regressions are automated; a live account run has not been qualified and is not represented by the local inference evidence.

Compatible saved transcripts can drive a fresh local acoustic pass without loading the recognition model or uploading audio. A mismatched source, range, stream, channel, language or model is rejected. Analyzer v3 adds independently measured source-edge silence so overlong Whisper alignments do not hide verified near-silent leading/trailing material.

See [contracts](IMPLEMENTATION.md#project-and-service-contracts), [procedure](QUALIFICATION.md), and [results](EVIDENCE.md). Measured speed and removal quantity are not editorial quality scores; human judgments remain part of acceptance.
