# ShotClutch application icons

Canonical original artwork: `shotclutch.svg`. Run `python scripts/generate-icons.py` (PySide6, Pillow >=12, ds_store==1.3.3 and mac_alias==2.2.3) to regenerate Windows ICO, macOS ICNS/Dock PNG, Linux hicolor, web favicon and the installer background. Outputs and attribution sidecars are committed, so application builds need no image tooling.
